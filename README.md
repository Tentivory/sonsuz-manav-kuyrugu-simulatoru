# Sonsuz Manav Kuyruğu Simülatörü

> **Dünyanın En Abartılı, En Ciddi, En Gereksiz ve En Çalışan Manav Kuyruğu Protokolü**

Bu repository, Türkiye'nin milli sporlarından biri olan "manav kuyruğunda bekleme" sanatını bilimsel ciddiyetle, abartılı bir şekilde ve tamamen işe yaramaz bir biçimde simüle eder. Kod gerçekten çalışır. Bekletir. Sabır sınar. Hayatını değiştirmez.

## Neden Bu Proje?

Çünkü:
- Domates seçmek için 47 dakika beklemek normaldir.
- Önümdeki kişi çantasında para ararken sen de aramalısın.
- Manav çay demliyorsa, sen de demlemelisin.
- Bu kod, bu gerçeği abartarak kutlar.

## Kurulum ve Kullanım

Python 3 yüklü olmalı (yoksa manav kuyruğunda beklerken öğren).

```bash
git clone https://github.com/Tentivory/sonsuz-manav-kuyrugu-simulatoru.git
cd sonsuz-manav-kuyrugu-simulatoru
python manav_kuyruk.py
```

**Uyarı:** Kod gerçek zamanlı bekler (ama 3 saniyeden fazla uyumaz, çünkü biz de sabırsızız).

## Özellikler

- Rastgele sebze seçimi (domates, salatalık, biber vs.)
- Absürt gecikme nedenleri
- Gerçekçi (değil) kuyruk uzunluğu
- Sabır testi
- Gizli mesaj (sakla, açma)

## Katkıda Bulunma

Katkıda bulunmak istiyorsan:
1. Kendi kuyruk hikayeni ekle.
2. Daha uzun bekletme süreleri öner.
3. Ama PR açma, çünkü kuyrukta zaten bekliyorsun.

## Lisans

Bu proje MIT lisansı altındadır. Yani kopyala, yapıştır, kendi manav kuyruğunda kullan. Ama kuyrukta öne geçmeye çalışma.
